Cinematic Counter‑Cartographies: Formal Refusal in Palestinian Cinema

Project site prototype: counter-cartographies.org / cinematic-refusals.org

Project summary

This project analyzes how Palestinian women filmmakers reframe and subvert surveillance aesthetics at Israeli checkpoints. It will present 3–5 checkpoint case studies (including a prison checkpoint) from films released 2000–2025 and document formal strategies of refusal (camera angles, editing, ellipses/offscreen space).
